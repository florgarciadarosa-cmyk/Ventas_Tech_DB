# Ventas Tech DB

Proyecto de base de datos relacional desarrollado para organizar y analizar información de ventas de una empresa de tecnología.

## Objetivo

El objetivo del proyecto es diseñar una base de datos que permita almacenar y consultar información relacionada con clientes, productos, categorías y ventas.

## Tecnologías utilizadas

- SQL

## Tablas principales

La base de datos está formada por las siguientes tablas:

- **clientes:** contiene información de los clientes.
- **productos:** contiene información de los productos disponibles.
- **categorias:** contiene las categorías de los productos.
- **ventas:** registra las operaciones de venta realizadas.

## Consultas de negocio

El proyecto también incluye consultas SQL para obtener información útil para el análisis del negocio, como:

- Total facturado por mes.
- Cantidad de pedidos.
- Ticket promedio.
- Productos con mayor facturación.

## Cómo utilizar el proyecto

Para ejecutar los scripts, se debe contar con un motor de base de datos compatible con SQL.
Primero se selecciona la base de datos correspondiente y luego se ejecutan los scripts SQL.
